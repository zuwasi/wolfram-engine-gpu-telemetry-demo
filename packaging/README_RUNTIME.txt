Wolfram Engine GPU Telemetry Demo Runtime

Run GpuTelemetryDashboard.exe to open the dashboard.
Run GpuTelemetryDashboard.exe --wolfram-engine-self-test to validate the .wls runner path.
Run GpuTelemetryDashboard.exe --wolfram-package-self-test to validate the .m package path.
Run GpuTelemetryDashboard.exe --self-test as a short alias for the .wls runner validation.

This runtime package intentionally excludes Wolfram Engine. Customers install and activate Wolfram Engine separately under their own license.
