Wolfram Engine GPU Telemetry Demo Runtime

Run GpuTelemetryDashboard.exe to open the dashboard.
Run GpuTelemetryDashboard.exe --wolfram-engine-self-test to validate that Wolfram Engine can calculate through wolframscript.
Run GpuTelemetryDashboard.exe --self-test to validate that GpuAnalysisDll.dll can be loaded and returns analysis JSON.

This runtime package intentionally excludes Wolfram Engine. Customers install and activate Wolfram Engine separately under their own license.
