# Customer Install Guide

This release demonstrates a customer-style deployment of a native Qt dashboard that uses **Wolfram Engine** locally as the calculation engine.

## What is included

- `GpuTelemetryDashboard.exe` - dashboard application.
- Qt runtime DLLs and plugins generated by `windeployqt`.
- `notebooks/GpuHealthReference.wl` - Wolfram Language calculation source.
- `notebooks/GpuHealthPackageExample.m` - traditional Wolfram package-file example with symbolic helper APIs.
- `notebooks/GpuHealthReferenceRunner.wls` - command-line Wolfram Engine bridge used by the app.
- `install.ps1` / `uninstall.ps1` helper scripts.

## What is not included

Wolfram Engine is **not redistributed** in this package. The customer installs and activates Wolfram Engine separately under their own Wolfram license.

## Customer prerequisites

1. Install Wolfram Engine from Wolfram.
2. Activate/license it according to Wolfram's instructions.
3. Ensure `wolframscript.exe` is on `PATH`.

Verify from PowerShell:

```powershell
wolframscript.exe -code '$Version'
```

Expected: a Wolfram version string, for example `14.3.0 for Microsoft Windows (64-bit)`.

## Install this demo

From the extracted release folder:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

Default install location:

```text
%LOCALAPPDATA%\Programs\WolframEngineGpuTelemetryDemo
```

The installer creates Start Menu and Desktop shortcuts.

## Run

Launch **Wolfram Engine GPU Telemetry Demo** from the Start Menu or Desktop.

Default demo flow:

1. Keep `Wolfram Engine Calculation Engine` selected.
2. Click **Start**.
3. The dashboard collects demo telemetry.
4. Wolfram Engine calculates the health report locally through `wolframscript`.
5. The formatted report appears in the dashboard.

## Self-tests

From the installed folder:

```powershell
.\GpuTelemetryDashboard.exe --wolfram-engine-self-test
.\GpuTelemetryDashboard.exe --self-test
```

Both commands validate the same Wolfram Engine integration path. `--self-test` is kept as a short alias for scripted checks.
